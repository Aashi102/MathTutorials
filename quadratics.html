📌 What Is a Quadratic?

A quadratic is an equation of the form ax² + bx + c = 0.

Example

x² + 3x + 2 = 0

→ (x + 1)(x + 2)

Solutions: x = -1, -2

🧮 Quadratic Formula

x = (-b ± √(b² - 4ac)) / (2a)

Example

Solve: x² - 4x + 3 = 0

Using formula → x = 1, 3
