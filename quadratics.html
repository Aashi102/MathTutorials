Quadratics

Quadratic functions create parabolas. They appear in physics, engineering, economics, and many real‑world models. Understanding quadratics gives you the power to analyze curved motion, optimize values, and solve a wide range of problems.

Standard Form

A quadratic expression or function is written in the form:

ax² + bx + c

Where:

  • a controls the width and direction of the parabola
  • b affects the tilt and position
  • c is the y‑intercept

Example: In the quadratic 2x² − 3x + 1:

  • a = 2
  • b = −3
  • c = 1

Vertex of a Parabola

The vertex is the highest or lowest point of the parabola. If a > 0, the parabola opens upward (minimum). If a < 0, it opens downward (maximum).

For a quadratic in standard form, the x‑coordinate of the vertex is:

x = −b / (2a)

Example: Find the vertex of y = x² − 4x + 3

a = 1, b = −4 x = −(−4) / (2 × 1) = 4 / 2 = 2 y = 2² − 4(2) + 3 = 4 − 8 + 3 = −1 Vertex: (2, −1)

Solving by Factoring

If a quadratic can be factored, set each factor equal to zero.

Example: Solve x² − 5x + 6 = 0

Factor: (x − 2)(x − 3) = 0 Solutions: x = 2 or x = 3

Quadratic Formula

When factoring is difficult or impossible, use the quadratic formula:

x = (−b ± √(b² − 4ac)) / (2a)

Example: Solve 2x² + 3x − 2 = 0

a = 2, b = 3, c = −2 Discriminant = 3² − 4(2)(−2) = 9 + 16 = 25 x = (−3 ± √25) / 4 x = (−3 ± 5) / 4 Solutions: x = 1/2 or x = −2

The Discriminant

The discriminant (b² − 4ac) tells you how many real solutions a quadratic has.

  • > 0 → two real solutions
  • = 0 → one real solution
  • < 0 → no real solutions

Example: For x² + 2x + 5:

b² − 4ac = 4 − 20 = −16 → no real solutions
