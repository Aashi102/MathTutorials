Foundations

Learn what variables are, how expressions work, and how to apply the order of operations.

Example: In x + 5, x is the variable.

Expressions

Expressions represent quantities that may change. You’ll simplify them, combine like terms, and evaluate them.

Example: 3x + 5x = 8x

Open Expressions Lesson

Equations

Equations state that two expressions are equal. Solving them means finding the value of the variable.

Example: x + 7 = 12 → x = 5

Open Equations Lesson

Inequalities

Inequalities compare values. Their solutions are often ranges, not single numbers.

Example: x + 3 > 7 → x > 4

Open Inequalities Lesson

Graphing

Learn how to plot points, understand slope, and graph lines.

Example: Slope = rise/run

Open Graphing Lesson

Polynomials

Polynomials are multi‑term expressions. You’ll add, subtract, and multiply them.

Example: (x + 3)(x + 2) = x² + 5x + 6

Open Polynomials Lesson

Factoring

Factoring breaks expressions into simpler pieces.

Example: 6x + 12 = 6(x + 2)

Open Factoring Lesson

Quadratics

Quadratics introduce parabolas, roots, and the quadratic formula.

Example: x² − 5x + 6 = 0 → roots 2 and 3

Open Quadratics Lesson

Functions

Functions map inputs to outputs. You’ll learn notation, domain, and range.

Example: f(3) = 2(3) + 1 = 7

Open Functions Lesson

Word Problems

Translate real‑world situations into algebraic equations.

Example: “Twice a number plus 3 is 11” → 2x + 3 = 11
