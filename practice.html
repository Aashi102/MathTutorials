Foundations

Begin your algebra journey by understanding the core building blocks: variables, constants, expressions, and the order of operations. This topic sets the stage for everything that follows.

Example: In the expression x + 5, the letter x represents a variable — a value that can change.

Expressions

Expressions represent quantities that may vary. Learn how to simplify expressions, combine like terms, and evaluate them for specific values. This topic builds fluency with algebraic structure.

Example: Combine like terms: 3x + 5x = 8x.

Equations

Equations show that two expressions are equal. Learn how to isolate variables, balance equations, and solve for unknown values using logical steps and inverse operations.

Example: Solve x + 7 = 12 → x = 5.

Inequalities

Inequalities compare quantities and often have multiple solutions. Learn how to solve them, graph solution sets, and interpret ranges in real‑world situations.

Example: Solve x + 3 > 7 → x > 4.

Polynomials

Polynomials are expressions with multiple terms. Learn how to add, subtract, multiply, and analyze polynomial expressions to understand their structure and behavior.

Example: Multiply binomials: (x + 3)(x + 2) = x² + 5x + 6.

Factoring

Factoring breaks expressions into simpler components. Learn how to factor out common terms, factor trinomials, and reverse polynomial multiplication.

Example: Factor 6x + 12 → 6(x + 2).

Quadratics

Quadratic equations introduce parabolas, roots, and the quadratic formula. Learn how to graph, factor, and solve quadratics using multiple methods.

Example: Solve x² − 5x + 6 = 0 → roots 2 and 3.

Functions

Functions map inputs to outputs. Learn how to evaluate functions, interpret notation, and understand domain and range.

Example: Evaluate f(3) for f(x) = 2x + 1 → 7.
