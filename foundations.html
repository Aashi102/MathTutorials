What is Algebra?

Algebra is the language of patterns and relationships. Instead of using only numbers, we use symbols to represent unknown or changing values.

Key Building Blocks

Variables

A symbol (like x) that represents a number.

Example: In 2x + 3, x is the variable.

Constants

A fixed value that does not change.

Example: In 2x + 3, 3 is a constant.

Expressions

A combination of variables, numbers, and operations.

Example: 4x - 7

Equations

A statement that two expressions are equal.

Example: 4x - 7 = 9

Evaluating Expressions

To evaluate an expression, substitute a value for the variable.

If x = 5, then 2x + 3 = 2(5) + 3 = 13.

Try It

If x = 4, what is 3x - 2?

3(4) - 2 = 12 - 2 = 10

Combining Like Terms

Terms are “like” if they have the same variable part.

2x + 5x = 7x

Simplify 3x + 4 + 2x - 1.

Combine x-terms: 3x + 2x = 5x
Combine constants: 4 - 1 = 3
Final: 5x + 3

Practice

  1. Identify the variable in 7x + 2.
  2. Evaluate 4x + 1 when x = 3.
  3. Simplify 2x + 3x - 4.
  4. Write an equation for: “Five more than a number is 12.”
