🔤 What Are Variables?

Variables are symbols (usually letters) that represent unknown numbers. For example, in the expression x + 5, the letter x is a variable.

Example

If x = 7, what is x + 5?

Solution: Substitute 7 → 7 + 5 = 12

➗ Solving Simple Equations

To solve an equation, isolate the variable by undoing operations.

Example

Solve: x - 3 = 9

Add 3 to both sides → x = 12
