🔤 What Are Variables?

Variables are symbols (usually letters) that represent unknown numbers.

Example

If x = 7, what is x + 5?

Solution: 7 + 5 = 12

➗ Solving Simple Equations

To solve an equation, isolate the variable by undoing operations.

Example

Solve: x - 3 = 9

Add 3 to both sides → x = 12
