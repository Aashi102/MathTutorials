Polynomials

Learn how to classify, add, subtract, and multiply polynomials.

What is a Polynomial?

A polynomial is an expression with multiple terms.

Example: 3x² − 5x + 2

Adding Polynomials

Combine like terms.

Example: (3x + 2) + (5x − 1)

3x + 5x = 8x → 2 − 1 = 1 → 8x + 1

Multiplying Polynomials

Use the distributive property or FOIL.

Example: (x + 3)(x + 2)

x² + 2x + 3x + 6 = x² + 5x + 6
