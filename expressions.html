Expressions

Learn how to simplify, evaluate, and manipulate algebraic expressions.

What Is an Expression?

An expression is a mathematical phrase made of variables, constants, and operations. Unlike an equation, it does not have an equals sign.

Examples: 4x - 7, 3(x + 2), 2a + 5b

Evaluating Expressions

To evaluate an expression, substitute a value for each variable.

If x = 3, then 2x + 4 = 2(3) + 4 = 10.

Try It

If x = 6, evaluate 5x - 8.

5(6) - 8 = 30 - 8 = 22

Combining Like Terms

Like terms have the same variable raised to the same power.

3x + 7x = 10x

Simplify 4x + 2 + 5x - 3.

Combine x-terms: 4x + 5x = 9x
Combine constants: 2 - 3 = -1
Final: 9x - 1

Distributive Property

The distributive property lets you multiply a number by a group of terms.

3(x + 4) = 3x + 12

Simplify 2(3x - 5).

2 × 3x = 6x
2 × -5 = -10
Final: 6x - 10

Practice

  1. Evaluate 3x + 2 when x = 4.
  2. Simplify 7x + 2x - 5.
  3. Use distribution to simplify 4(2x + 3).
  4. Simplify 5a + 3b - 2a.
