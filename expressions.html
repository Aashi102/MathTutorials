Algebraic Expressions

Learn how to simplify, evaluate, and manipulate expressions.

What is an Expression?

An expression is a combination of numbers, variables, and operations.

Unlike equations, expressions do not have an equals sign.

Combining Like Terms

Terms are “like” if they have the same variable and exponent.

Example: Simplify 3x + 5x

3x + 5x = 8x

Evaluating Expressions

Substitute values for variables.

Example: Evaluate 2x + 3 when x = 4

2(4) + 3 = 8 + 3 = 11
