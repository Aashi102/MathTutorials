Graphing Basics

Learn how to plot points and graph linear equations.

Plotting Points

A point is written as (x, y).

The x‑value moves left/right, and the y‑value moves up/down.

Example: Plot (3, −2)

Move 3 right, 2 down.

Slope

Slope measures steepness: rise / run.

Example: Find slope between (1, 2) and (3, 6)

Rise = 4, Run = 2 → slope = 2

Slope‑Intercept Form

y = mx + b

  • m = slope
  • b = y‑intercept
