Functions

A function is a rule that assigns exactly one output to each input. Functions help us describe relationships between quantities.

What Is a Function?

A function takes an input (usually x) and produces an output (usually f(x)). Every input must have exactly one output.

Example: f(x) = 2x + 1

If x = 3, then f(3) = 7.

Function Notation

f(x) is read as “f of x.” It simply means “the output when x is the input.”

Example: If f(x) = x² − 4, find f(5).

f(5) = 25 − 4 = 21

Domain & Range

The domain is all possible inputs. The range is all possible outputs.

Example: For f(x) = x², the range is all numbers ≥ 0.

Squaring any number gives a non‑negative result, so the smallest output is 0.

Functions in the Real World

Functions appear everywhere: pricing models, physics formulas, population growth, and more.

Example: A taxi charges $3 plus $2 per mile.

Cost function: C(m) = 3 + 2m
