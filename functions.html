📌 What Is a Function?

A function is a rule that assigns each input exactly one output.

Example

If f(x) = 2x + 3, find f(4).

→ 2(4) + 3 = 11

🧮 Function Notation

f(x) means “the output when x is the input.”

Example

f(x) = x² − 1

f(5) = 25 − 1 = 24
