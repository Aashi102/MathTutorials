Functions

Understand inputs, outputs, and function notation.

What Is a Function?

A function pairs each input with exactly one output.

Example: f(x) = 2x + 1

Function Notation

Find f(3) if f(x) = 2x + 1.

f(3) = 2(3) + 1 = 7

Tables and Graphs

You can represent a function with a table of values or a graph.

Practice

  1. Evaluate f(0) if f(x) = 3x - 2.
  2. Is the relation {(1,2), (1,3)} a function?
  3. Find g(4) if g(x) = x^2.
  4. Describe how you’d graph y = 2x + 1.
