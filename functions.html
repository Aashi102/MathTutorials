Functions

Understand inputs, outputs, and function notation.

What is a Function?

A function assigns exactly one output to each input.

Think of it like a machine: you put in x, you get out f(x).

Function Notation

f(x) means “the output when x is the input.”

Example: If f(x) = 2x + 1, find f(3)

f(3) = 2(3) + 1 = 7

Domain & Range

The domain is all possible inputs.

The range is all possible outputs.

Example: For f(x) = x², what is the range?

All values ≥ 0
