Functions

Understand inputs, outputs, and function notation.

What is a Function?

A function assigns exactly one output to each input.

Function Notation

f(x) means “the output when x is the input.”

Example: If f(x) = 2x + 1, find f(3)

f(3) = 2(3) + 1 = 7
