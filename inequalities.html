📌 What Is an Inequality?

An inequality compares two values using symbols like <, >, ≤, ≥.

Example

Solve: x + 3 < 10

Subtract 3 → x < 7

⚠️ Important Rule

When you multiply or divide by a negative number, the inequality sign flips.

Example

Solve: -2x ≥ 8

Divide by -2 → x ≤ -4
