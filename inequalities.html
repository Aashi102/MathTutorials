Inequalities

Learn how to solve and graph inequalities on a number line.

What Is an Inequality?

An inequality compares two values using symbols like <, >, ≤, ≥.

x + 3 > 7

Solving Inequalities

Solve inequalities just like equations — except for one key rule:

When you multiply or divide by a negative number, flip the inequality sign.

Solve x - 5 < 2.

Add 5 → x < 7

Inequalities with Negatives

Solve -3x ≥ 12.

Divide by -3 → flip sign → x ≤ -4

Graphing Solutions

Use open circles for < or >. Use closed circles for ≤ or ≥.

x ≥ 2 → closed circle at 2, shade right
