Solving Inequalities

Learn how to compare values and solve inequality statements.

What is an Inequality?

An inequality compares two values using symbols like:

  • < (less than)
  • > (greater than)
  • ≤ (less than or equal to)
  • ≥ (greater than or equal to)

Solving Inequalities

Treat inequalities like equations — except when multiplying or dividing by a negative.

Example: Solve x + 3 > 7

Subtract 3 → x > 4

Important Rule

If you multiply or divide both sides by a negative number, the inequality sign flips.

Example: Solve −2x ≤ 10

Divide by −2 → x ≥ −5
